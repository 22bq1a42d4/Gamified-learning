## 📌 Project Overview

The **Gamified Learning Platform with Hierarchical Monitoring System** is an interactive educational web application designed to enhance student engagement through **gamification techniques** such as points, badges, leaderboards, and progress tracking.

It is especially focused on improving **learning accessibility in rural areas**, while enabling teachers and administrators to monitor and evaluate student performance efficiently.

---

## 🎯 Objectives

* 🎓 Improve student engagement using gamified learning
* 🌐 Provide an interactive digital learning environment
* 👨‍🏫 Enable teachers to monitor and evaluate performance
* 📍 Support educational development in rural areas

## ✨ Key Features

* 🎮 Gamified learning modules
* 📊 Real-time student progress tracking

## 🏗️ System Architecture

The platform follows a **3-layer hierarchical architecture**:

### 👨‍🎓 Student Layer

* Access learning modules
* Complete quizzes and activities
* Earn rewards and track progress

### 👨‍🏫 Teacher Layer

* Monitor student performance
* Assign tasks and quizzes
* Evaluate progress

### 🏢 Admin Layer

* Manage users and courses
* Monitor system activity
* Generate reports and insights

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/22bq1a42d4/Gamified-learning.git
cd Gamified-learning
```

### 2️⃣ Create Virtual Environment

```bash
python -m venv venv
```

### 3️⃣ Activate Environment

**Windows**

```bash
venv\Scripts\activate
```

**Mac/Linux**

```bash
source venv/bin/activate
```

### 4️⃣ Install Dependencies

```bash
pip install -r req.txt
```

### 5️⃣ Apply Migrations

```bash
python manage.py migrate
```

### 6️⃣ Run Server

```bash
python manage.py runserver
```
